# R8 지형 인계

`data/concepts/landforms.json`은 카르스트·빙하·건조·해안·하천·화산·판 경계·산지의 형태와 형성 작용을 강의 표·원문에 연결한다. 지형·과정 대상 63건이며 지리적으로 서로 다른 63장소라는 뜻은 아니다.

`data/concepts/landform-places.json`은 구이린·할롱베이·그랑 칭기·파묵칼레와 기존 위치 모드의 산맥·하천·지형 기준점 64기록을 다룬다. 기존 점이면 좌표와 장소 ID, 선·광역 도형이면 원래 geometry를 보존했다. 선이나 광역 지역에 임의의 새 지도점을 넣지 않았다. 어떤 장소는 강의의 복합 행 제목으로 남아 있어 `place:null`이다.

돌리네·칼데라의 함몰 원인, 피오르·리아스의 침수 전 골짜기, 모레인·에스커의 운반 주체, 석회 동굴 공간과 종유석의 형성 작용을 구별한다. 지역명만으로 넓은 지역 전체에 한 지형·한 기후를 적용하지 않는다. 새로운 경관 사진은 추가하지 않았다.
