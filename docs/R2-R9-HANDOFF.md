## 연결 규칙

`complete:false`의 누락을 거짓으로 판단하지 않는다. `sourceReading`은 근거 읽기, `suppliedData`는 수치·연도·분류·출처를 제시하는 연습이다. `candidatePool`과 `requiresGiven`도 필수 조건이다. 역사적 통계의 연도를 지우거나 현재 판본으로 덮어쓰지 않는다.

새 에너지 `relations`·`orders`는 기존 허용 목록의 구조를 따른다. 단, `primaryEnergy` 구성과 지표를 엔진에 등록해야 한다. `validatedIndicatorOrders`는 별도 어댑터가 필요하다. 도시 계층의 상대 관계도 별도 지표 연결이 필요하다.

## 확인

새 검사 26개 통과. 원자료 34개의 해시·크기를 확인하고 세 생성 스크립트의 오프라인 재생성 검사를 통과했다. 앱 연결을 하지 않았으므로 이 검사를 화면·문항 생성 테스트로 표현하지 않는다. 구체적인 미해결 자료와 사용 제한은 `audit/request-coverage-20261022.json`을 따른다.
