# R5 종교·문화 인계

`data/concepts/religion.json`, `religion-practices.json`, `religion-places.json`은 종교·종파, 의례·금기, 성지를 다룬다. `culture.json`은 게르·갓쇼즈쿠리·열대 고상 가옥·건조 지역 가옥의 차이, `conflicts.json`은 카슈미르·쿠르드·카탈루냐·스코틀랜드·플랑드르 등 갈등의 복합 원인을 담았다. 비슷한 가옥 형태가 같은 적응 원인이라는 뜻은 아니다.

`data/religion-composition-extension.json`에는 Pew 2025 배포 원자료의 134개국, 2010·2020 비율과 같은 해 인구를 비반올림 상태로 담았다. 크리스트교·이슬람교·불교·힌두교·유대교·무종교·기타의 7개 범주를 유지했다. 포르투갈도 포함한다.

새 파일의 `populationUnit`은 명이다. 기존 앱의 종교 파일은 만 명을 사용하므로 기존 인구값과 단위 변환 없이 섞으면 안 된다. 분류·인구·비율·연도를 한 출처 안에서 맞춘다. 모든 종교 속성이나 장소의 좌표를 빠짐없이 구축한 것은 아니며, `place:null`은 임의 좌표를 넣지 않은 상태다. 지역 전체를 한 종교·언어·단일 갈등 원인으로 단정하지 않는다.

보완판은 `linkedLocations`에 메카·메디나·바라나시·로마·바티칸의 개별 기존 지점과 갠지스강·카탈루냐·스코틀랜드·플랑드르의 원래 선·영역 도형을 연결했다. 복합 카드의 `place:null`만 보고 위치 자료가 없다고 판단하지 않는다. 사진이나 모든 지역의 새 점 좌표는 필수 미완료 항목으로 세지 않는다.
