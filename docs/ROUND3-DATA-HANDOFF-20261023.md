## 제조업: 해결한 범위와 남은 범위

워싱턴주의 항공 우주(3364) 출하액은 2014·2015년 모두 후속 **2016 발표판**에서도 `D`다. 해당 파일의 원숫자 `0`을 플래그 없이 읽으면 안 된다. 2015년 부가가치는 36,155,985천 달러로 공개되어 있지만 출하액을 대신할 수 없다. 원행은 `asm-area-2016.zip`의 `ASMAREA2012.dat`에 있다. 캘리포니아의 2014·2015년 수치도 후속 판본에서 개정되어 있어, 이번 검토 행으로 기존 연간 발표판을 조용히 바꾸지 않는다.

대신 공개 AIES에서 2023·2024년 워싱턴주 3364 출하액을 확보했다. 기존 2016~2022와 연결해 검토하면 **2016~2024의 9개 연도** 모두 워싱턴주의 항공 우주 출하액 비중이 캘리포니아·텍사스·미시간보다 높다. 검토 결과와 해마다의 두 값은 `aerospaceDirectionChecks`에 있다. 2023 AIES 방법서 PDF 11쪽은 기존 조사와 새 표본의 시계열 연결 방법을 설명한다. 이 검토는 틀 담당이 7개년 예외를 재검토할 재료이며, 이번 묶음이 허용 목록이나 엔진을 자동 수정하지는 않는다.

캘리포니아·워싱턴주의 비공개 자동차 3361 출하액은 AIES에서도 계속 `D`다. BEA의 ‘자동차·차체·트레일러·부품’은 공개되지만 **부가가치이며 범위도 더 넓다**. 3361의 비공개 값을 메우는 자료로 쓰지 않는다.

2027학년도 6월 5번의 범례는 BEA의 제조업 업종 구분과 잘 대응한다. 새 BEA 자료에서 2024년 구성비도 계산해 `candidateData`에 넣었다. 그러나 이는 **원출처 후보라는 추론**이다. 원문 문제지는 통계 기관과 ‘생산액’의 정의를 제시하지 않으며, 개별 막대에 정확한 숫자도 없다. 따라서 원출처·지표의 확정 상태는 모두 false다. 2024 AIES는 2026-09-03 발표여서 6월 시험 원표의 근거로 삼을 수 없다. 현재 개정 BEA 값도 기출 given으로 바꾸지 않는다.

오하이오를 미시간·워싱턴주와 함께 다룬 기출 근거는 이번 확인 범위에서 확보하지 못했다. 확인한 제조업 기출은 2016학년도 9월 7번(오하이오·캘리포니아·텍사스)과 2027학년도 6월 5번(캘리포니아·텍사스·워싱턴주·미시간)이다. 전체 구기출에 그런 조합이 절대 없다는 판정은 아니다. 새 회상 관계를 추가하지 않는다.

## 세계 도시 요청의 정확한 형태

2016학년도 6월 13번에는 도시별 수치 계층표가 없다. **최상위·하위 계층 평균의 상대 특징을 3축 그림에서 고르는 문제**다. 하위는 본사 수가 적고, 생산자 서비스 비중이 낮고, 최근접 동일 계층 도시까지 거리가 가깝다. 원문 정답은 D(④)이며 강의 `L1-B1695·1698`과 대조했다. 이 형태를 구현할 개념 카드와 원그림을 제공한다. 도시별 숫자 등급표는 새로 만들지 않았다.

토론토 단서는 기존 검토 범위 `L1-B1690~1709` 앞의 **L1-B1673**에서 찾았다. 원문은 ‘토론토는 미국이 아니라 캐나다의 온타리오호 연안 도시이다.’다. 단서에서 이미 준 캐나다·호수 사실을 후속 회상 문제로 반복하지 않는다.

## 하천과 관측소

하천은 이번 5개와 앞서 제공한 메콩·라인을 합쳐 7개에 검토된 목록이 있다. 이라와디는 말리·엔마이 합류 이후, 짜오프라야는 나콘사완 합류 이후라는 범위를 명시했다. 공식 설명과 기존 Natural Earth 본류선을 함께 확인했고, 각각 491개·312개 선 꼭짓점이 미얀마·타이 안에 있다. 이 좌표 검사는 정밀 국경 측량을 대신하지 않는다.

잠베지의 목록은 잠비아·앙골라·나미비아·보츠와나·짐바브웨·모잠비크다. **보츠와나의 짧은 본류 국경 구간을 포함**한 범위다. 잠비아 대사관의 전체 경로 설명과 대조했다. 유역 8개국의 말라위·탄자니아를 본류 국가로 더하지 않는다. 콩고·나일은 여전히 보류다. 나일은 Main Nile·백나일·청나일·상류 호수 경로를 구분해야 한다. 목록의 완전성 검토는 기출에 없는 국가 쌍의 회상 승인과 다르다.

아부자 WMO 65125는 자료 자체가 전혀 없는 경우가 아니다. 원본 `Nigeria_WMO_Normals_9120.xlsx`의 `Abuja_65125` 시트에서도 **E59(1월 월평균)=E41(1월 일최고 평균)=35.15279569900001℃**다. E50의 일최저 평균은 약 18.52℃다. CSV만의 변환 문제가 아니며 원표의 의심 값을 보존했다. 1월을 최고·최저의 평균으로 고치지 않고, 사용 가능 배열의 1월을 null로 두었다. 2~12월 11개 값은 원표대로 보존하되 완전 기후 그래프에는 연결하지 않는다. 키토 M0024 강수는 여전히 보류다. 확인한 NCEI Ecuador 파일 목록의 Rumipamba Salcedo 84143은 다른 지점이다.

## 적용·재생성

전달 ZIP의 `apply_followup.py`를 사용한다. 먼저 충돌만 검사하고 `--apply`로 적용한다. 기존 `data/us-state-manufacturing-series.json`의 SHA-256이 기준과 다르면 적용 전에 멈춘다. 틀 담당이 그 파일을 수정했다면 보완 스크립트의 입력과 방향 검토를 먼저 대조해야 한다.

```bash
python3 apply_followup.py /path/to/geography
python3 apply_followup.py /path/to/geography --apply
```

수동 검사는 다음과 같다. Python은 표준 라이브러리만 필요하다.

```bash
python3 scripts/verify-round3-sources.py
python3 scripts/build-round3.py --check
node --test tests/round3-data.test.cjs
node scripts/build-entity-kb.cjs --report
```

`data/round3-sources/` 작업 다운로드 폴더와 전체 강의·워크북·전체 문제지는 필요하지 않다. 원자료 ZIP의 30개 스냅숏·선별 근거와 기존 정규화 제조업 파일만으로 9개 출력을 재생성한다. 기출 그림은 선택 문항만 발췌했고 원본 URL·해시·페이지·발췌 좌표를 manifest에 보존했다. CWC 인더스 자료는 웹에서 본문을 확인했으나 바이트 다운로드가 401이어서, 그 제한을 명시한 사실 요약으로 보존했다.

보호 파일 `assets/exam-engine.js`, `assets/exam-themes.js`, `exam.html`은 수정하지 않았다. 생성 자산 `assets/entity-kb.js`는 전달 파일에서 제외하며 현재 체크아웃의 입력으로 다시 생성한다.

## 검증 계약 보완

`tests/extensions.test.cjs`는 기존 카드의 좌표 스냅숏 검사를 유지하면서, 새 카드가 현재 `index.html`을 좌표 출처로 명시하면 실제 포함 자료와 geometryData 재정의를 대조하도록 확장했다. 또한 모든 세트가 무조건 `complete:false`라는 옛 가정을, 명시된 유한 대상 범위와 모든 대상의 값이 일치할 때만 `complete:true`를 허용하는 검사로 보완했다. 전체 강의가 있는 환경에서도 이 범위를 검사한다. 기존 자료의 불완전한 세트를 완전하다고 바꾸지는 않았다.
