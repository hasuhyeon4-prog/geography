# 2026-10-21 Claude 인계: 지도 단계와 기후 관측소 자료

## 결정과 작업 구분

- **지도 A~E는 국가 단위 주제 전부에 적용**한다. 인구·경제·수출 상위 품목·수출 구성·종교·전력 모두 해당한다. 경제 블록·대륙 주제는 기존 형태를 유지한다.
- 표의 (가)~(다)를 지도 A~E와 대응시키는 방식으로 한다. 정답을 공개하기 전에는 지도에 국가 이름을 표시하지 않는다. 자료 식별과 위치 지식을 한 문항에서 연결하며, 표 없이 위치만 찍는 문제로 대체하지 않는다. 기존 이름 후보 방식은 접근성/학습용 선택으로 남길 수 있다.
- 지도, 전력 총발전량, 적도·본초 자오선 사실의 화면/엔진 구현은 Claude 담당이다. 이번 커밋은 **새 데이터·재생성 스크립트·검증·인계 문서**이며 기존 화면을 바꾸지 않는다.
- 기후는 **1991~2020 관측소 기반 평년값**으로 준비했다. WMO 회원국 제출 자료를 우선하고, 없는 지점은 JMA의 같은 기간 관측소 자료와 ECCC의 공식 관측소 연결 자료로 보충했다. 격자는 사용하지 않았다.

## 바로 읽을 파일

- `data/climate-normals.json`: 41개 지점의 자료/보류 사유/사용 가능 범위. **그래프 가능한 38개**, 기온만 읽을 수 있는 지점을 더하면 39개다.
- `data/climate-sites.json`: 기존 `WGClassification.byId.climateCities`의 이름·지도 좌표·강의 기후형과 자료 출처 연결.
- `data/climate-sources/manifest.json`: 모든 원자료의 URL·내려받은 날짜·SHA-256. 원문 CSV/HTML은 `data/climate-source-snapshots.zip`에 원래 경로·바이트 그대로 보존했다. `path`는 ZIP 내부 경로다.
- `scripts/build-climate-data.py`: 표준 Python 라이브러리로 원자료를 파싱한다. 최고·최저기온 평균으로 월평균을 만들어 넣지 않는다.
- `tests/climate-data.test.cjs`: 누락/오류가 출제 풀에 들어가지 않는지, 단위·월 순서·남반구 계절·계산 및 재생성을 검사한다.

```sh
python3 scripts/build-climate-data.py --check
node --test tests/*.cjs
```

107개 테스트가 통과했다. 브라우저에서 기후 모드가 동작한다는 뜻은 아니다. 기후 화면은 이 자료를 받아 다음 단계에서 구현해야 한다.

## 엔진에서 사용할 규칙

```js
const pool = data.sites.filter(s => s.usage.climateGraph);
// temperatureC / precipitationMm: 각각 1월~12월, ℃ / 월 강수량 mm
// mapPoint: 기존 지도 [경도, 위도]
// station.latitude / longitude: 실제 자료 관측소 위치
```

`sourceId`로 출처를 찾는다. `station.id`는 관측소 ID이며 `idScheme`을 함께 읽는다. 보고타의 21205791은 5자리 WMO 번호가 아닌 콜롬비아의 관측소 ID다. `normalPeriod:[1991,2020]`는 매년 바뀌는 관측 연도가 아닌 평년의 기준 기간이다.

- `usage.climateGraph`: 기온·강수 자료를 제시하는 그래프/계산 문항에 사용 가능.
- `usage.temperatureReading` / `precipitationReading`: 해당 변수만 읽는 문항에 사용 가능.
- `usage.climateTypeRecall:false`: 이 수집 작업으로 강의 기후형과 새 관측소 수치의 완전 일치를 인증하지 않았다. `lectureClimate`를 월별 숫자의 자동 정답으로 그대로 연결하지 않는다. 특히 아래 경계 지점은 별도 검토가 필요하다. 이 플래그는 기후형 개념 문항 전체를 없애라는 뜻이 아니다.
- `derived`: 최한월/최난월·연교차·JJA/DJF 강수 합과 비중. `meanOfMonthlyTemperatureC`는 월평균 12개의 산술평균이며 원출처의 연평균과 같다고 가정하지 않는다. 연 강수량도 반올림된 월별 값의 합과 원출처 연계가 조금 다를 수 있다. 계산 문제는 **화면에 제시한 값**으로 계산한다.
- 연교차 + 최한월 = 최난월, 누적 강수 차이, 강수 집중률, 반구·대륙 동안/서안·해안/내륙·고도와 연결한다. 근소한 관측소 간 수치 순서를 외우게 하지 않는다.
- 기준 기간과 관측소명은 출처 접기에서 확인 가능하게 한다. 숫자나 평년 기간 암기를 학습 목표로 만들지 않는다. 과거의 특정 시기 변화가 목표인 기출은 해당 자료를 별도로 제시한다.

## 자료 상태와 주의점

| 지점 | 처리 | 이유 |
|---|---|---|
| 아부자 | `hold`, 기온/기후 그래프 제외. 강수만 가능 | WMO 제출 1월 평균 35.2℃가 평균 최고 35.2℃와 같고 최저는 18.5℃. 월평균 12개 평균과 연평균도 크게 다름. 임의로 26.9℃ 등으로 고치지 않음 |
| 그린란드 내륙 | `partial`, 기온만 가능 | Summit Tower 대표 관측소, 지도 점에서 약 52km. 강수가 없음. 0mm로 채우면 안 됨 |
| 키토 | `missing`, 풀 제외 | WMO Ecuador 제출은 약 94km 떨어진 Rumipamba-Salcedo 한 지점이며 키토가 아님. JMA 동일 지점의 새 평년도 미확인. 1981~2010·격자·다른 고산 도시를 대신 넣지 않음 |
| 오클랜드 | 월별 자료 사용, 좌표 교정 이력 보존 | WMO 원문 경도 171.804°E가 NOAA ISD 동일 관측소 931100의 174.800°E와 다름. 지도 연결 좌표만 두 번째 공식 출처로 교체 |
| 로마 | Fiumicino 16242 채택 | 가까운 Ciampino 16239는 6~8월 강수가 공란. 두 관측소를 섞지 않고 Fiumicino 한 곳의 기온·강수를 함께 사용 |
| 시안 | JMA 57036 채택, 관측 연수 불확실성 표시 | WMO 대안 Jinghe 57131은 월별 연수가 16년. JMA 시안은 실제 월별 연수 미표시. 30년 완전 관측이라고 표시하지 않음 |
| 마나우스 | 그래프 가능, Af/Am 단독 판별 보류 | 강의 Af와 달리 새 관측소 최건월 56.1mm가 Af의 60mm 경계 아래 |
| 시안·디트로이트 | C/D 경계 판별 주의 | 최한월이 0℃ 또는 -3℃ 경계 가까이 있어 분류 기준·관측소/평년 선택의 영향을 받음 |
| 아디스아바바 | 그래프 가능, 정확한 고도 수치 문제 제외 | JMA 관측소 고도 공란. 고도 값을 다른 공항 관측소에서 가져와 덧붙이지 않음 |
| 몬트리올 | ECCC 공식 composite 사용 | 기온 A(WMO 3-and-5 rule), 강수 C(20년 이상) 등급. 강수는 눈을 포함한 총강수이며 rainfall만 사용하지 않음 |

관측소 자료가 모두 완전한 30년 기록이라는 뜻은 아니다. WMO 원문에 `NOY`가 있는 경우 월별 실제 연수를 보존했다. 없는 경우 NCEI의 min24 파일은 30년으로 가정하지만 실제 연수를 확인했다는 표현은 하지 않는다. JMA 보충 6개 지점(치타·상파울루·리마·아디스아바바·시안·보스토크)은 제공기관의 최소 채택 기준이 8년이고 각 지점의 월별 연수는 미표시다. 이들은 **제시 자료 읽기**에 사용하고 정밀 순위 회상에 사용하지 않는다.

## 멕시코·독일 도시화율: 확인 진전

`audit/urbanization-vintages-20261021.json`에 원문 확인, UN 두 판본의 같은 2015년 수치와 국가 정의/원자료 메타데이터를 보존했다.

| 2015년 도시화율 | UN WUP 2018판 | UN WUP 2025판의 국가 정의 자료 |
|---|---:|---:|
| 멕시코 | 79.285% | 77.1904% |
| 독일 | 77.200% | 80.6974% |
| 베트남 | 33.809% | 32.3811% |

2020학년도 6월 14번의 79.3·77.2·33.8은 2018판을 반올림한 값과 일치한다. **문제 원문 각주에는 기간만 있고 통계 기관·판본명은 없다.** 따라서 ‘원문이 WUP2018이라고 명시했다’고 쓰지 않는다.

2025판의 **국가별 정의(national definitions)** 값이 현재 WDI와 일치한다. 국제 공통 DEGURBA 파일을 잘못 사용한 결과로 설명할 근거는 없다. 독일의 정의 설명은 2018판의 행정구역 인구밀도 기준에서 2025판 메타데이터의 인구 2,000명 이상 locality로 달라졌고, 멕시코 원자료도 새 CELADE 재집계/2020 센서스가 반영되어 있다. 수정 기여도를 나라별로 완전히 분해한 것은 아니다.

학습 처리는 그대로다. 두 나라 도시화율 순서는 회상에서 제외하고 원문 표를 읽게 한다. 같은 2015년 자체가 판본에 따라 달라졌으므로 학생에게 ‘어느 연도 순서를 외우라’고 맡기면 해결되지 않는다. 다년도 한 판본 검증과 판본 간 일관성은 별개의 검증이다.

## 전력 근거 재점검

최종 강의 2권 P07을 다시 확인했다. 새 석탄/가스 **전체 발전원 1위** 관계를 추가할 만큼 명시적인 본문 근거는 찾지 못했다. 다음은 확인 가능한 범위다.

| 강의 위치 | 실제로 명시한 내용 | 적용 범위 |
|---|---|---|
| p.43·49 | 네팔 2015년 전력의 수력 99.8%, 브라질 수력 의존 | 기존 사례 유지 |
| p.44·45 | 폴란드 석탄, 중국·인도 석탄, 러시아·이란 가스 | **1차 에너지** 자료. 전력 1위 근거로 옮기지 않음 |
| p.54 | 수력 발전량 중국 > 캐나다, 풍력 발전량 독일 > 프랑스 | 발전원별 **절대량** 비교. 전체 발전원 구성의 1위와 다름 |
| p.54·55 | 노르웨이 수력 > 풍력, 덴마크 풍력 > 태양광, 아이슬란드 수력 > 풍력 | 명시된 두 발전원 사이의 비교 |
| p.54 | 캐나다·브라질은 수력의 국가 사례, 국내 비중 높음 | 캐나다가 모든 발전원 중 1위라는 명제까지 본문에 적힌 것은 아님 |

Claude가 제안한 **총발전량 열 + 3개국 모두 근거 식별**은 진행하면 된다. 새 나라를 늘리기 위해 1차 에너지 근거를 전력으로 바꾸지 않는다. 총발전량은 비중과 같은 출처·연도·발전 범위여야 하며 비율×총량은 제시 자료로 계산하게 한다.

820문항 색인은 전수 선지 재검토 완료 목록이 아니다. 이번 커밋도 이를 완료했다고 주장하지 않는다. 추가 허용 관계를 넣을 때는 기출의 실제 명제·지표·분모·비교 범위를 확인해야 한다.
