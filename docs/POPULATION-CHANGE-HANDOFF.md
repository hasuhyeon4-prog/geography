# R7 두 시점 변화 자료 인계

`data/urbanization-change.json`은 UN WUP 2025 F14·F15의 1950~2050 국가·지역별 도시 인구·촌락 인구·총인구·도시화율이다. 국가별 도시 정의를 사용한다. DEGURBA의 도시·준도시·농촌 분류를 이 자료에 섞지 않는다. 원자료 천 명을 명으로 바꿨다. 2026~2050 전망은 관측값이라고 표시하지 않는다.

`data/fertility-change.json`은 WDI 국가별 합계 출산율과 WDI 원지역 집계다. `data/fertility-un-regions.json`은 UN WPP 2024를 OWID가 배포한 파일에서 이름에 (UN)이 붙은 공식 지역 계열만 골랐다. OWID 자체 합성 대륙이나 국가 출산율의 단순 평균을 사용하지 않았다. WDI와 UN의 서로 다른 판본·기간을 하나의 연속 계열로 붙이지 않는다.

`data/us-migrants-by-origin.json`은 UN DESA IMS2024 Table 1의 미국 목적지·양성 합계, 1990·1995·2000·2005·2010·2015·2020·2024년 stock이다. 확보된 미국 출신국 기록 중 기존 국가명에 대응되는 53개국을 인계했다. 원본에 없는 출신국이나 세부 값을 0으로 만들지 않는다. 남성+여성=전체를 검사했다.

UN 원본 서버가 403이라 동일한 공식 배포 XLSX의 공개 사본 2개를 비교했고 SHA-256이 일치했다. 공식 서버 원본과 직접 바이트 대조한 것은 아니므로 이 전달 경로를 manifest에 기록하고 제시 자료 연습으로 제한했다.

`data/us-migrants-lecture-given.json`은 강의가 제시한 2020년 멕시코·인도·독일·세네갈의 별도 값이다. 현재 IMS 판본으로 덮어쓰지 않는다. 시점의 거주 이주민 수를 1년 유입 인구나 순이동으로 읽지 않는다.
