# R1 농목업 자료 인계 · 2026-10-21

농목업 자료·근거·개념 카드 묶음이다. 엔진·화면 연결은 Claude 담당이며 이번 묶음은 R1이다.

## 준비한 범위

- FAOSTAT 공식 QCL·TCL: 2013~2024년. FBS: 2013~2023년. 없는 해나 값을 보충하지 않았다.
- 밀·쌀·옥수수·보리·커피·카카오·차 생산 자료, 원품목·가공 단계별 무역량과 무역액.
- 소·돼지·양·염소 사육 두수. 물소 및 소·물소 합계, 소·돼지·양 육류 생산량은 별도.
- FBS의 밀·쌀·옥수수·보리·곡물 전체 생산·교역·이용 자료.
- 기존 한국어 국가명과 연결된 134개국, 세계·지역 15개 항목. 다른 보고 지역은 원래 FAO 코드와 이름을 보존.
- 개념 카드: 19개 대상, 속성 세트 9개, 판단 문장 28개.
- 검증 항목 56개 중 **50 active, 4 reversed, 2 insufficientYears**. 재생성 후 이전 검수 기록과 상태·검증 연도가 모두 일치했다.

## 읽기와 출제 규칙

단일 국가 값은 `data.seriesByArea[data.entities['중국'].areaCodes[0]]['qcl-production:밀']['2023']`처럼 읽는다. `indicators[id]`에 원출처 영역·항목 코드·단위·배율이 있다. 생성 값은 생산·교역·육류 t, 면적 ha, 두수 마리, 무역액 천 US$, 비율 %, 단수 kg/ha다. FBS의 1000 t만 1,000배 했다.

북아메리카는 Northern America+Central America+Caribbean, 앵글로아메리카는 Northern America, 라틴 아메리카는 Central America+Caribbean+South America다. 러시아는 FAO 유럽에 포함된다. 합성 지역은 지표별 공통 연도만 합산한다. 비율·단수는 분자와 분모를 각각 합한 뒤 나누며, 지역 비율을 더하지 않는다. Python `resolve(data, name, indicator)`가 이를 처리한다.

`rankings`의 상위 10개국은 참고 자료이며 회상 허용 목록이 아니다. 세계·대륙·중국 합계 등 중복 집계를 국가 순위에서 제외했다. 회상에는 판정 `active`만 쓴다.

- **QCL·TCL·FBS를 섞지 않는다.** QCL 쌀은 벼, TCL은 벼·현미·정미·쇄미 등 별도 항목, FBS는 가공품 환산을 포함한 쌀 및 제품이다. 임의 0.67 환산이나 제품 무게의 단순 합산을 하지 않는다. FBS를 정미 기준이나 원곡 교역 자료라고 표시하지 않는다. 현재 FBS 세계 쌀 생산은 약 8억 t다.
- 수출/생산 비율은 FBS의 같은 품목·같은 연도로 계산한다. 식용 공급량을 실제 소비량·섭취량이라고 부르지 않는다.
- QCL 차 생엽 667과 가공 차 675는 다르다. 2023년 세계 생산은 각각 약 3,100만 t와 730만 t다. TCL 차 무역을 생엽 생산량과 나눠 건조 차 수출 비율로 표시하지 않는다.
- 소 866은 물소 제외, 물소 946과 소·물소 1746은 별도다. 육류 생산과 두수를 구별하고 음식 금기를 두수 0의 근거로 쓰지 않는다.
- 추정·보정 깃발은 원본 행에 보존했다. 없는 값을 0으로 만들지 않는다.
- 개념 카드의 scope 안에서만 속성을 사용한다. 모두 complete:false다. 비배타 세트의 누락·다른 값을 거짓 근거로 쓰지 않는다. 서남아시아와 아시아 기원을 상충하는 선택지로 만들지 않는다. 확정적인 거짓 보기는 출처가 있는 statements를 우선 사용한다.

## 회상에서 제외한 항목

| 후보 | 결과와 처리 |
|---|---|
| 중국>인도 쌀 생산·중국 세계 1위 | 현재 QCL 2023·2024년은 인도가 더 큼. 기출 2023년의 중국·인도·방글라데시 순서는 given으로 보존하고 미표기 수치는 추정하지 않음 |
| 미국 옥수수 수출 세계 1위 | TCL 2019·2023년에 1위가 아님. 수치를 제시하는 식별·계산으로 사용 |
| 아시아 양>돼지>소 | 2015~2018년 양/돼지, 2019년 돼지/소 순서가 다름. 2024년의 기출 순서를 모든 해로 확대하지 않음 |
| 북아메리카>유럽 밀 수출/생산 비율 | Caribbean 밀 생산 공란 때문에 합성 지역 비율을 완전하게 만들 수 없음. 원기출 생산 2019~2021·무역 2019/20~2021/22 자료를 따로 제시 |
| 일본 곡물 전체 순수입 | 선택한 FBS 계열에 일본 해당 값이 없어 연수 부족. 이 계열로 재검증 완료라고 표시하지 않음 |

중국·인도는 같은 2023년의 기출 순서와 현재 FAOSTAT 순서가 다르다. 원문이 통계 기관·판본을 특정하지 않아 차이의 원인을 단정하지 않는다. 두 판본 순서를 모두 암기하게 하지 않는다.

## 범위와 복구 기록

기존 원본 엑셀 추출 기록은 농목업 연관 현재 문항 25행, 농목업 주 지식 문항축 17행, 명제 92행, 구기출 색인 31행이다. 전수 선지 재판독 완료 수가 아니다. 비교 대상·내용이 생략된 명제를 추측해서 확장하지 않았다. 기존 검토는 강의 P06 3~34쪽과 2027학년도 9월 17번 원문·해설 대조를 포함한다.

작업공간 정리 후 기존 검수 파일 2개를 GitHub에서 바이트 그대로 복구했다. 코드·카드·통계는 작업 기록과 공식 원자료로 재생성하고 다시 검사했다. 이전 56개 항목의 판정과 검증 연도는 모두 일치한다. 현재 통계 ZIP에는 전체 강의·기출 PDF를 재수록하지 않았다. 기존 원문 대조의 출처·해시를 검수 기록으로 보존했다.

Claude는 자료·개념·허용 목록 읽기, 작물·가축 식별, 후속 판단과 표의 출처·연도·단위·벼/정미·물소 포함 여부 표시를 연결하면 된다. 기호 작물의 직접 소비량, 회계연도·원곡 기준 원기출 무역표, 사진·분포 도해는 추가 보완 범위다. R2~R9는 이번 완료 범위가 아니다.
