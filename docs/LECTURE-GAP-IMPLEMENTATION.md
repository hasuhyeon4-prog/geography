# 하위 학습 목표 구현 상태

기준: `2665750` · 2026-10-25

이 변경은 573개 전체의 완료가 아니다. **검증 43개 · 구현 301개 · 미구현 229개**다. `구현`은 연습 화면에 내용이 연결되었다는 뜻이며 완료 기준 전부를 확인한 상태는 아니다. 모든 하위 목표가 `검증`인 묶음만 완료다.

- 새 OX 637문장: 기존 `facts.html`에 연결. 기존 217개 ID·정답·학습 기록은 유지.
- `materials.html`: 30개 자료형·계산 주제, 식별 후 <보기> 판단, 틀린 문항 다시 풀기.
- `concepts.html`: 재구성 비교표 6개. 겹치는 지각 변화는 모든 대상을 묶은 답으로 처리.
- `exam.html`: 위도선 통과·지도 대표점 비교·상대 생산성·도시화 역산 연결.

현재 완료 묶음: G009, G022, G024, G063, G070, G136.

## 검증 범위

관측소 누적 차분·편차 복원, 태양 계산, 부양비 역산, 시작 비중 가중 증가율, GIS 원문 예시와 동점·가중치, 허용 범위와 정오 양방향 생성을 검사한다. 실제 Chromium 화면 검사는 설치 파일 다운로드 실패로 수행하지 못했다. DOM 제어 코드의 클릭·중복 채점·재방문 복습을 검사했고 SVG 그래프를 렌더해 확인했다.
