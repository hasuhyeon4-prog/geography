# R3 국가 지식 보완 인계

`data/entity-facts.json`에 강의 개별 사실 49건과 기존 사실을 보존했다. 하천·언어·내륙국·식민 지배국의 각 값은 원문 블록으로 추적한다. 모든 세트는 불완전하므로 누락을 거짓으로 판단하지 않는다.

OPEC 빈 세트는 EI2025 공식 XLSX Definitions!A60의 12개국 목록으로 채웠다. 이는 해당 발행판 기준의 제시자료이며 현재 회원국이라고 표시하지 않는다. 콩고 공화국과 콩고 민주 공화국을 구별한다.

인구 집단은 2020학년도 6월 13번의 기존 원문 판독 기록에서 파라과이 혼혈 80% 초과·아르헨티나 유럽계 80% 초과만 복구했다. `ethnicity`의 두 최다 집단은 이 제시자료에 한정한다. `prior-country-exam-evidence.json`에 기존 판독 기록을 그대로 보존했으며 이번 새 원문 시각 판독으로 표현하지 않는다. 다른 국가의 현재 최다 집단을 추정하지 않는다.

`data/entity-facts-supplement.json`에 이란-페르시아어, 튀르키예-튀르키예어, 케냐-스와힐리어/영어의 공식 출처 보충값을 넣었다. 강의·기출의 명시적 회상 근거가 없어 suppliedData 전용이다. 튀르키예 의회 PDF와 케냐 법개혁위원회 HTML은 원자료를 보존했다. 이란은 외교부 공식 페이지의 검색 색인에서 확인했으나 원 HTML이 redirect loop여서 이 한계를 명시했다.

국가 설명의 근거 연결은 1,659건이다. 중복 문단을 포함하며 문제 수를 뜻하지 않는다. 요청 19개국 모두 식별 후보가 있다. 라오스는 타이 언급 때문에 잘못 제외했던 비엔티안 문장을 수동 승인했다. 앙골라는 후보군 [앙골라, 브라질, 독일]과 2023 부양비 제시자료가 반드시 필요하다. `eligibleIdentification`만 보지 말고 `candidatePool`, `practice`, `requiresGiven`을 함께 확인한다.

기존 820문항 검수-강의 연결을 보존했다. 실제 원문에 없는 공용어·지배국·최다 집단을 모든 국가에 일괄 부여하지 않는다.
